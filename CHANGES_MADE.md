# Changes Made to pppower Package

## Summary

Simplified package structure following best practices for R packages,
similar to the `pwr` package model.

## Completed Changes

### 1. Separated Simulation Code ✅

- Created `inst/simulations/` folder
- Moved research scripts:
  - `R/simulation_mean.R` → `inst/simulations/simulation_mean.R`
  - `R/simulation_ols.R` → `inst/simulations/simulation_ols.R`
- Added README explaining the simulations folder

### 2. Removed Thin Wrapper Functions ✅

- Removed `power_curve_gaussian()` - use
  `power_curve_mean_dgp(family = stats::gaussian())` instead
- Removed `power_curve_binomial()` - use
  `power_curve_mean_dgp(family = stats::binomial())` instead

**Note:** These functions were thin wrappers that added no value. Users
can achieve the same result by calling
[`power_curve_mean_dgp()`](https://yiqunchen.github.io/pppower/reference/power_curve_mean_dgp.md)
directly with the `family` argument.
